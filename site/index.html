LLM은 분석가, 코드가 리스크매니저

LLM은 매매 제안만 생성합니다. 실제 주문 체결 여부는 결정론 리스크 게이트가 결정합니다.

모의투자가 디폴트

실계좌 전환은 환경변수 KIS_LIVE=1 을 명시해야만 가능합니다. 기본값은 항상 페이퍼 트레이딩.

티커 화이트리스트

KOSPI200 화이트리스트 외 종목은 게이트에서 거부. LLM이 존재하지 않는 종목을 주문하는 환각을 차단합니다.

멱등 주문 ID + reconciliation

멱등 client_order_id 와 체결 대사로 중복 주문·유실을 방지합니다.

멀티 LLM 백엔드 — .env 한 줄로 전환

API 키가 필요 없는 CLI 백엔드부터 로컬 Ollama까지. LLM_PROVIDER 값만 바꾸면 됩니다.

Provider인증비고

ollama로컬localhost:11434 · llama3.1 / qwen2.5 등
// tauri desktop

데스크톱 관측 UI · 4-뷰

Vite + React + TypeScript + Tauri 2.x. 백엔드(127.0.0.1:8765)에 HTTP + WebSocket 으로 연결.

TAB 01

Dashboard

LLM provider/모델, 유니버스 크기, 리스크 파라미터, HALT 상태, 포지션 테이블, 현재 equity/cash.

TAB 02

Run cycle

티커 입력 → WebSocket 스트림. settings_loaded → features_computed → proposal_built → risk_gate_decision → order_placed 까지 단계별 카드.

TAB 03

Journal

오늘 자 journal/YYYY-MM-DD.md 렌더링. 모든 매매 의사결정의 thesis/risks/거부 사유 보존.

TAB 04

Observability

3초 주기 equity 샘플링 sparkline + 백엔드 상태 메트릭.

시작하기

클론 → KIS 모의계좌 키 발급 → LLM 백엔드 선택 → 스모크 테스트 → 페이퍼 루프.

# 1. 클론 후 설치
git clone https://github.com/cskwork/kr-ai-trader
cd kr-ai-trader
python -m venv .venv && source .venv/bin/activate
pip install -e ".[dev]" && pre-commit install

# 2. KIS 모의계좌 키 입력 (apiportal.koreainvestment.com)
cp .env.example .env

# 3. LLM 백엔드 — API 키 0원 권장
#   LLM_PROVIDER=claude_code_cli

# 4. 스모크 테스트 + 페이퍼 루프
make smoke-llm
make smoke-kis
make paper

# 5. (충분한 검증 후) 실계좌
KIS_LIVE=1 make live
KIS Open API 모의투자로 시작

한국투자증권 apiportal에서 모의투자 계좌 키를 발급받아 .env 에 입력하세요. 실계좌 전환은 명시적 플래그가 필요합니다.

백테스트

make backtest UNIVERSE=kospi200 FROM=2024-01-01 TO=2025-12-31 — vectorbt 래퍼로 파라미터 변경 후 재검증.

데스크톱 앱

make api 로 백엔드를, 다른 터미널에서 make desktop 으로 Tauri 관측 UI를 실행합니다.
